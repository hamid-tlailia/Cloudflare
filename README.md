# خادم المجلس على Cloudflare

نسخة الخادم مكتوبة لـ **Cloudflare Workers + Durable Objects**: كل غرفة تصبح كائناً دائماً مستقلاً يحمل حالتها ويستقبل اتصالات WebSocket مباشرة.

## لماذا Cloudflare هنا؟

- **لا نوم ولا إقلاع بارد.** الاستضافات المجانية الأخرى تُنيم الخادم بعد خمول، فيتأخر أول اتصال ١٠–٣٠ ثانية. هنا الاستجابة فورية دائماً.
- **قريب من اللاعب.** الغرفة تعمل على أقرب مركز بيانات، فيقلّ زمن الاستجابة.
- **الخطة المجانية تكفي.** الكائنات الدائمة متاحة مجاناً بحدود ١٠٠٬٠٠٠ طلب يومياً، ورسائل WebSocket تُحتسب بنسبة ٢٠:١ — أي أن مليون رسالة تُحسب ٥٠٬٠٠٠ طلب فقط. جولة لودو كاملة لا تتجاوز بضع مئات من الرسائل.

> استعملنا **WebSocket Hibernation**: الغرفة تنام بين الرسائل ولا تُحتسب عليها مدة تشغيل، فتبقى ضمن الحد المجاني حتى لو تُركت مفتوحة ساعات.

## النشر

```bash
cd server-cloudflare
npm install
npx wrangler login          # يفتح المتصفح مرة واحدة
npx wrangler deploy
```

ستحصل على عنوان مثل `https://majlis.<اسمك>.workers.dev`. اكتبه في التطبيق هكذا:

```
wss://majlis.<اسمك>.workers.dev
```

هذا كل شيء — لا قاعدة بيانات ولا إعدادات إضافية.

## التجربة محلياً

```bash
npx wrangler dev
# ثم في التطبيق: ws://localhost:8787
```

## الإعدادات

في `wrangler.toml` أو من لوحة Cloudflare:

| المتغيّر | الغرض |
|---|---|
| `ALLOWED_ORIGINS` | نطاقات مسموح لها بالاتصال (`*` للجميع) |
| `TURN_URL` · `TURN_USER` · `TURN_PASS` | خادم TURN للصوت عند الشبكات المغلقة (اختياري) |

## نقاط الوصول

- `GET /health` — حالة الخادم
- `GET /new` — رمز غرفة جديد
- `GET /ice` — خوادم الصوت
- `WS /ws?code=XXXXX` — قناة اللعب

التطبيق يكتشف تلقائياً أي نسخة من الخادم يخاطب: إن وجد `/new` استعمل مسار الغرف، وإلا تعامل مع خادم Node العادي في مجلد `server`.

## الحدود

- ٤ لاعبين لكل غرفة.
- من ينقطع اتصاله يبقى مقعده محجوزاً ٤٥ ثانية ثم يُزال.
- تُحذف الغرفة تلقائياً حين يغادرها الجميع.
- الحالة داخل الكائن الدائم؛ نشر نسخة جديدة من الخادم ينهي الغرف القائمة.

## أيّهما أختار؟

| | Cloudflare | Node (مجلد `server`) |
|---|---|---|
| الإقلاع البارد | لا يوجد | ١٠–٣٠ ثانية على الباقات المجانية |
| التوزيع | عالمي | خادم واحد في منطقة واحدة |
| التكلفة | مجاني ضمن الحدود | مجاني مع نوم |
| التشغيل محلياً | يحتاج wrangler | `npm start` مباشرة |

للنشر الحقيقي: **Cloudflare**. للتجربة السريعة على جهازك: نسخة Node أبسط.
